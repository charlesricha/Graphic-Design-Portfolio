# **App Name**: DesignVerse

## Core Features:

- Interactive Portfolio: Showcase graphic design projects in an interactive grid layout with hover animations.
- About Me Section: Create a sleek card layout featuring a professional photo, bio, skills, and resume download.
- Services Section: Outline all services offered in a clear, concise format.
- Testimonials Display: Include testimonials from past clients and peers in a card format.
- Contact Form: Create an interactive contact form with social links and email.
- AI Design Feedback: AI-powered tool to analyze user-submitted design briefs and provide feedback with creative design direction.

## Style Guidelines:

- Primary color: Navy Blue (#2E3141) to set a slightly dark aesthetic, providing a professional, sleek look. This dark background will ensure other colors stand out. 
- Background color: Charcoal (#1A1A1A), a very dark hue of the primary, further emphasizing the dark theme.
- Accent color: Teal (#46B4B4) for interactive elements and highlights, delivering a futuristic feel and good contrast.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern look.
- Use a grid layout with large images to showcase projects effectively.
- Apply subtle hover animations to portfolio items and interactive elements to enhance user experience.
